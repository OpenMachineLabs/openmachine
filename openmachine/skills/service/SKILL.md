# Runtime and service operations

Use this guide only for authorized operator work. Reading a newer guide or source
does not upgrade an installed server, enable grants or refresh a client's catalog.
Inspect status and the original maintenance intent before changing anything.

| Work | Read next |
| --- | --- |
| First installation, grants, manual serving or tunnel setup | [Setup](../overview/setup.md) |
| Managed macOS lifecycle, configuration changes, compatibility or recovery | [Management](management.md) |
| Prepare, connect or diagnose a configured SSH target | [SSH](ssh.md) |
| Build or prepare a trusted offline Python/Core/Git payload | [Runtime payload](runtime-payload.md) |

Select exact reviewed artifacts and preserve original environments, target archives,
state and stable locks. Never repair a compatibility gate by deleting history or
fabricating an installation manifest. Unknown or pending work retains original IDs;
software rollback does not reverse user effects. Local readiness, installed tests,
tunnel readiness and real ChatGPT acceptance are separate observations.
