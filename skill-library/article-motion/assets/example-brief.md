# Starter brief: carry the evidence

Source: the illustration Skill's [complete archive-review example](../../anthropic-style-illustrations/examples/article.md)
and [figure specification](../../anthropic-style-illustrations/examples/figure.json).
Use its existing case reference P2 for traceable transformation.

Audience: a reader considering the archive team's review process.
Main idea: the request and its evidence remain connected through each handoff.
The article describes responsibilities, not measured speed or reliability.

The 12-second starter carries one request and a smaller evidence note through
request intake, catalogue checking, access review and a response. It briefly
exposes the catalogue's clarification branch. The final response is a decision
with notes; it is not an invented approval or a claim that every request succeeds.
The camera follows the record, then reveals the full path. Captions name the
current responsibility without resetting the whole canvas between stages.

This brief explains the example; `starter.cjs` owns its executable timing. Adapt
both for a real article. The starter is a working authoring exercise, not proof
that an arbitrary article has been converted or that the output has been reviewed.
