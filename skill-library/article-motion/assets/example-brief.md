# Starter brief: carry the evidence

Source: the illustration Skill's [complete archive-review example](../../anthropic-style-illustrations/examples/article.md)
and [figure specification](../../anthropic-style-illustrations/examples/figure.json).
Use its existing case reference P2 for traceable transformation.

Audience: a reader considering the archive team's review process.
Main idea: the request and its evidence remain connected through each handoff.
The article describes responsibilities, not measured speed or reliability.

The 12-second starter begins close to one request and its attached evidence.
The catalogue note separates from the record; an unresolved detail remains marked
for clarification. The access note then opens out from the same packet with an
unresolved condition. Finally, the original request and both notes gather into a
response packet without converting either unresolved marker into approval.

Its motion beats are **attached packet -> separated notes -> traceable response**.
The framing opens to make room for the notes, then closes around the gathered
packet. Labels describe the currently exposed responsibility; there is no static
row of workflow nodes. The note count and spacing are conceptual, not measured
workload or elapsed time. This demonstrates a physical handoff mechanism; a real
article still needs its own visual argument, composition and timing.

This brief explains the example; `starter.cjs` owns its executable timing. Adapt
both for a real article. The starter is a working authoring exercise, not proof
that an arbitrary article has been converted or that the output has been reviewed.
